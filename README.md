# xbook — эмоциональный атлас книги

Минималистичный интерактивный прототип: загрузка EPUB, FB2, TXT и Markdown → воспроизводимые фрагменты → восемь независимых эмоциональных оценок → карта, treemap, график и экспорт датасета.

## Запуск

Node.js 22.12+.

```sh
npm ci
cp .env.example .env
npm run dev
```

Откройте http://127.0.0.1:5173. Без ключа доступны демонстрационная книга, импорт собственного текста, разбиение и экспорт. Демо-история состоит из повторяющихся оригинальных фрагментов; оценки синтетические и явно помечены в UI и экспорте. Для загруженных книг оценки не выдумываются.

Для реального анализа добавьте `TYPESAFE_API_KEY` в `.env`, перезапустите сервер и нажмите «Анализировать». Ключ остаётся на сервере. Только эта кнопка отправляет текст книги в TypeSafe. `.env` исключён из Git. Платные вызовы в ходе разработки не выполнялись: без ключа live-анализ не проверен, API-контракт проверен на тестовых ответах.

```sh
npm run build
npm start
```

Production-сервер также слушает только loopback по умолчанию. Это однопользовательский прототип. Перед размещением сервера с API-ключом в интернете необходимы аутентификация пользователей, квоты расходов и долговечное хранилище заданий. Статическую сборку `dist/` можно смотреть без AI-backend.

## Что работает

- EPUB: порядок глав из OPF spine; извлечение заголовка и автора.
- FB2: metadata, основной текст без notes/binary; кодировка XML, включая Windows-1251.
- TXT / Markdown: UTF-8, Markdown анализируется как исходный текст.
- До 20 МБ на файл, 5 млн символов текста; ограничения распаковки EPUB.
- Условные страницы до 1 800 знаков, по возможности без разрыва слов. Вторая гранулярность — абзацы, длинные также делятся по лимиту.
- Карта последовательности, treemap с площадью по количеству фрагментов, фильтр эмоций, временной график, чтение выбранной страницы и восемь оценок.
- Экспорт JSON с текстом, границами, интенсивностями, уверенностью, фактической моделью и исходными ответами; CSV с текстом и оценками.
- До четырёх параллельных запросов к Jev; 8 независимых Score-вопросов в каждом. Повторы при перегрузке API, остановка и продолжение с пропуском готовых фрагментов.

## Значение данных

Нормализация v1: NFC, CRLF→LF, схлопывание горизонтальных пробелов, не более двух последовательных LF, trim. Границы — UTF-16 offsets в нормализованном тексте, конец исключён. Фрагменты без потерь покрывают весь этот текст.

Страница — фиксированный объём, **не** точная вёрстка бумаги определённым шрифтом. Семантическое разбиение Jev ещё не реализовано. Абзацы не выдаются за смысловые блоки.

Радость, доверие, страх, удивление, грусть, отвращение, гнев, ожидание оцениваются независимо по уровням 0–4, затем делятся на 4. Это выраженность эмоционального тона текста, не вероятность возникновения эмоции у читателя. Оценки не обязаны суммироваться в 100%. Уверенность модели — отдельное поле.

- Цвет ячейки: максимальная оценка; при максимуме < 0,2 — нейтральный цвет.
- Интенсивность: максимум восьми оценок.
- Палитра и средняя интенсивность: взвешены по длине оценённых фрагментов.
- Treemap: площадь пропорциональна числу фрагментов с данной ведущей эмоцией, не интенсивности.
- График: до 160 окон; в большом тексте отображаются средние по фрагментам окна.
- JSON отмечает полный / частичный / отсутствующий анализ. Демо-данные помечены `synthetic-demo-v1`.

Данные хранятся в памяти вкладки. Перезагрузка, новая загрузка или смена разбиения сбрасывают текущие оценки; экспортируйте нужные результаты заранее. PDF/OCR, DRM, MOBI, библиотека нескольких книг, физическая вёрстка и семантические блоки — за рамками первого прототипа.

## Проверки и доставка

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

Unit-тесты проверяют сохранность и детерминизм разбиения, нейтральный класс, пропорциональность treemap, валидацию ответов и нормализацию Score. Browser-тесты проверяют импорт трёх форматов, порядок EPUB spine, отсутствие выдуманных результатов, фильтры, чтение, экспорт, мобильный размер и продолжение после частичного сбоя.

GitHub Actions запускает build, unit и browser-тесты, сохраняет `xbook-preview-build` с `dist/`. У нового репозитория preview-хостинг не подключён; артефакт сборки не является опубликованным сайтом. Production deployment не выполняется.

## Реализация

React + TypeScript + Vite, Recharts, JSZip, Express. `src/model.ts` — воспроизводимый датасет и treemap; `src/import.ts` — импорт; `server-analysis.mjs` — Jev adapter; `server.mjs` — локальный API и dev/production server.

Контракт интеграции: [TypeSafe HTTP API](https://docs.typesafe.ai/api), [Score](https://docs.typesafe.ai/primitives/score), [composite scoring](https://docs.typesafe.ai/patterns/composite-scoring). Текущая модель запрашивается как `jev-latest`; возвращённый version ID сохраняется в каждом результате.
